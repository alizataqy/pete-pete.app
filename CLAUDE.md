# Commit Rules
- Do not add Co-Authored-By lines to commit messages.
- Do not commit automatically. Only provide the commit message and let the user commit manually.

## Agent skills

- Wajib menggunakan pendekatan / skill "Grill Me" sebelum eksekusi atau perencanaan fitur/perubahan: interogasi kebutuhan, uji asumsi, cari edge cases, dan pastikan arsitektur solid sebelum menulis kode.
